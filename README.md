# 🧠 Interactive GK Quiz

An interactive General Knowledge quiz application built using **HTML, CSS, and JavaScript**.

## 🚀 Features

- 🎯 10 General Knowledge questions
- 🎲 Random question selection
- 🚫 Questions don't repeat during a quiz
- 🔘 Dynamically generated answer buttons
- ✅ Correct/Wrong answer feedback
- 📊 Automatic score calculation
- ➡️ Next question functionality
- 🔄 Restart quiz option
- 🎨 Clean and responsive user interface
